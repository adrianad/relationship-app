# Internationalization Guide for Relationship App

This document explains how the internationalization (i18n) system works in the Relationship App, particularly focusing on how it interfaces with the LLM prompt system.

## Key Concepts

1. **UI Localization**: All user-facing text in the app is localized through Flutter's official i18n system.

2. **Dropdown Mappings**: The app shows localized text to users while keeping original English values for the LLM prompts.

3. **Prompt Handling**: Prompts are constructed using English option values, but we specify the output language to the LLM.

## File Structure

- **ARB Files**: Located in `lib/l10n/`, define translations for all languages
  - `app_en.arb`: English (base language)
  - `app_es.arb`: Spanish
  - `app_fr.arb`: French
  - `app_de.arb`: German
  
- **Generated Files**: Located in `lib/generated/` after running the generation script
  - Generated by Flutter's i18n system
  - Imported via `import 'package:app/generated/app_localizations.dart'`

## Adding New Languages

1. Create a new ARB file in `lib/l10n/` following the naming pattern `app_<language_code>.arb`
2. Copy all keys from `app_en.arb` and translate the values
3. Add the new locale to the `supportedLocales` list in `lib/providers/language_provider.dart`
4. Run `./generate_localizations.sh` to generate the necessary files

## LLM Prompts and Internationalization

The app maintains a separation between UI language and prompt construction:

1. **UI Display**: Shows translated dropdown options and UI elements in the user's selected language
2. **Internal Storage**: Keeps original English values for settings
3. **Prompt Construction**: The LLM prompt uses English values but specifies that output should be in the target language

Important note: In `lib/views/settings_view.dart`, the `getLocalizedOption()` helper method maps between the original English values and the localized display values.

## Regenerating Localization Files

After making changes to any ARB files, run:

```
./generate_localizations.sh
```

This will:
1. Remove any temporary implementations
2. Generate official Flutter localization files in the correct location
3. Update imports to use the non-deprecated approach

## Adding New UI Strings

1. Add the string to all ARB files with appropriate translations
2. If it's a dropdown option:
   - Add it to `getLocalizedOption()` in `lib/views/settings_view.dart` 
   - Keep the original (English) value for prompt construction
3. Run the generation script to update the generated files

## Testing Localization

1. Change the app language in the settings
2. Verify that:
   - All UI text changes appropriately
   - Dropdown options and buttons display in the selected language
   - Generated questions are in the selected language
